# Quiz-verse
Web Technologies Pair Project
## ​Description

​*Quiz Verse is a web-based trivia application that dynamically pulls questions from a database, tracks each player's score in real time, and gives instant, informative feedback after every answer. Rather than hard-coding a fixed list of questions, the application generates quizzes dynamically, making every session feel fresh and replayable. 

**​Project Goals**

-Build a fully functional, browser-based quiz application that generates questions dynamically.

​-Implement accurate score tracking and immediate, meaningful feedback so users understand their performance.

*​Practice collaborative software development as a pair, including task division and version control with Git/GitHub.

​-Deliver a polished, user-friendly interface that is enjoyable to use across desktop and mobile devices.

**​Planned Features**

​-Dynamic Question Generation: Questions are fetched dynamically from a database, with configurable category and difficulty.

-Score Tracking: Tracks the player's score in real time as questions are answered and stores results for review.

​-Instant Feedback: After each answer, the user immediately sees whether their choice was correct, the correct answer if they were wrong, and a short explanation.

-​Timer per Question: A visible countdown timer is applied to each question to add challenge; unanswered questions are auto-submitted when time runs out.

-Category & Difficulty Selection: Users can choose a topic and difficulty level before starting a quiz. 

-​Leaderboard / High Scores: Top scores are stored and displayed on a leaderboard so players can compare results. 

-​Responsive UI: The interface adapts cleanly to desktop, tablet, and mobile screen sizes.

**​Target Audience**

-​Students and self-learners looking for a fun way to reinforce knowledge.

-Casual gamers and trivia enthusiasts.

-​Teachers and trainers who want to informally quiz students.

-Friend groups wanting to compete on a shared leaderboard.
